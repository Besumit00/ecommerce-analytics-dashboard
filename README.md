# E-Commerce Analytics Dashboard

## Project Overview
This project analyzes Brazilian e-commerce data using Excel Data Modeling, Pivot Tables, Pivot Charts, KPIs, and interactive dashboards.

The dashboard provides insights into:
- Revenue trends
- Regional sales performance
- Customer payment behavior
- Operational efficiency
- Product category performance
- Customer satisfaction

---

## Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Data Model Relationships
- Pivot Charts
- Slicers

## Key KPIs
- Total Revenue

- Delivery Success Percentage

---

## Key Business Insights
- Revenue increased steadily throughout 2017 before stabilizing in 2018.
- São Paulo contributed disproportionately high revenue, indicating strong regional concentration.
- Credit cards dominated customer transactions across the platform.
- Delivered orders accounted for the majority of transactions, reflecting strong fulfillment performance.
